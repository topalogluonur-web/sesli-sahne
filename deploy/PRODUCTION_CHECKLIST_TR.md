# Production Checklist

## Backend

- [ ] Backend internette HTTPS adresinden açılıyor.
- [ ] `/api/health` cevap veriyor.
- [ ] Admin şifresi `0000` değil.
- [ ] `ADMIN_JWT_SECRET` değiştirildi.
- [ ] Upload klasörü kalıcı disk üzerinde.
- [ ] Database dosyası kalıcı disk üzerinde.
- [ ] Günlük yedek planı var.
- [ ] TTS için Python + edge-tts kurulumu test edildi.

## Admin

- [ ] Admin production API URL ile build edildi.
- [ ] Admin login çalışıyor.
- [ ] PDF yükleme çalışıyor.
- [ ] Ses üretme çalışıyor.
- [ ] Kütüphaneye alma çalışıyor.

## Mobil

- [ ] Mobil app production API URL ile build edildi.
- [ ] Kullanıcı girişi çalışıyor.
- [ ] Kütüphane görünüyor.
- [ ] Favoriler profil bazlı çalışıyor.
- [ ] Geçmiş profil bazlı çalışıyor.
- [ ] Ses dosyaları internetten oynuyor.
- [ ] Ekran kapanınca player davranışı test edildi.

## Store / Hukuki

- [ ] Privacy Policy yayınlandı.
- [ ] KVKK aydınlatma metni yayınlandı.
- [ ] Çocuk güvenliği politikası yayınlandı.
- [ ] Store açıklamaları hazır.
- [ ] Demo hesap bilgisi hazır.
