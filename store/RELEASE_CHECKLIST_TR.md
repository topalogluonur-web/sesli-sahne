# Store Yayın Kontrol Listesi

## Teknik

- [ ] Backend production ortamına alındı
- [ ] API URL production olarak ayarlandı
- [ ] SQLite yerine production veritabanı planı netleşti
- [ ] Ses/görsel dosyaları cloud storage'a taşındı veya production sunucu ayarlandı
- [ ] Android AAB build alındı
- [ ] iOS build planı yapıldı
- [ ] Uygulama ikon/splash kontrol edildi
- [ ] Arka planda ses gerçek cihazda test edildi
- [ ] Kayıt/giriş/çıkış test edildi
- [ ] Demo hesap hazırlandı

## İçerik

- [ ] En az 5-10 kaliteli içerik kütüphanede
- [ ] Her içerikte kapak var
- [ ] Her içerikte açıklama var
- [ ] Her bölümde ses dosyası var
- [ ] Telif/lisans durumu net
- [ ] Çocuk içerikleri yaşa uygunluk açısından kontrol edildi

## Hukuki / Store

- [ ] Gizlilik politikası URL'i hazır
- [ ] KVKK aydınlatma metni hazır
- [ ] Kullanım şartları hazır
- [ ] Google Play Data Safety formu hazırlandı
- [ ] App Store age rating soruları hazırlandı
- [ ] Çocuk güvenliği beyanları kontrol edildi
- [ ] Destek e-postası aktif
